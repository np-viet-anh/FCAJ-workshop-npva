# Summary Report: "AgentForge – Deepdive Day 1"

### Event Objectives

- Provide foundational knowledge of **Amazon Bedrock AgentCore** – AWS's platform for building AI Agents
- Guide participants through hands-on practical labs for deploying real AI agents
- Connect the FCAJ community across a 3-day in-depth Agent AI workshop series

### Event Details

| Detail | Information |
|--------|-------------|
| **Event Name** | AgentForge – Deepdive Day 1 |
| **Date & Time** | 09:00 – 12:00, August 1, 2026 (Saturday) |
| **Location** | Floor 26, Bitexco Financial Tower, Ho Chi Minh City |
| **Role** | Attendee |
| **Series** | 3-Day AgentForge Workshop – Day 1 |

### Event Agenda

#### 09:00 – 10:00 | Foundations: Introduction to Amazon Bedrock AgentCore

**Presentation content:**

- Overview introduction to the 3-day AgentForge workshop
- **Amazon Bedrock AgentCore Overview** – architecture and core components:
  - **Runtime**: The agent execution environment where the agent processes requests and performs actions
  - **Gateway**: The routing and connection management layer between the agent and external services
  - **Identity**: Authentication and authorization mechanisms for agents (integrated with Amazon Cognito)

#### 10:00 – 11:00 | Hands-on Lab

**Practical activities:**

- 🚀 **Deploy a basic agent in AgentCore** – Deploy a basic agent on Amazon Bedrock AgentCore from scratch
- 🔗 **Connect external tools and Knowledge Bases** – Connect the agent to external tools and a Knowledge Base
- 🌐 **Build a Web UI and integrate Amazon Cognito authentication** – Build a web interface and integrate user authentication via Amazon Cognito

### Key Takeaways

#### Technical Knowledge

- **Amazon Bedrock AgentCore**: Understood the overall architecture and the role of each component (Runtime, Gateway, Identity) in an agent system
- **Agent deployment**: The end-to-end process of deploying a complete agent on AWS
- **Knowledge Base integration**: How to connect an agent to external data and knowledge sources to improve response accuracy
- **Amazon Cognito**: Integrating user authentication into AI agent applications through Amazon Cognito

#### Practical Skills

- Hands-on experience deploying an agent directly via the AWS Console/CLI during the lab
- Configuring the connection between an agent and external tools
- Building a simple Web UI with integrated authentication for an AI application

#### Agent System Design Thinking

- Clearly understood the differences between **Runtime**, **Gateway**, and **Identity** – the three pillars of a complete agent system
- Recognized the importance of **authorization and authentication** in AI agent applications serving real users
- Appreciated the potential of **Knowledge Base** in making an agent smarter with domain-specific knowledge

### Event Experience

Attending **"AgentForge – Deepdive Day 1"** was an incredibly practical and in-depth learning experience. As the first day of a 3-day intensive Agent AI workshop series, it laid a solid foundation for the entire learning journey.

#### Building a solid knowledge foundation

- The introduction to **Amazon Bedrock AgentCore** was presented clearly, allowing me to understand the overall agent system architecture right from the start
- The clear separation of concepts — **Runtime – Gateway – Identity** — gave me a clear mental model for designing and deploying agents going forward

#### Hands-on "learning by doing"

- The hands-on lab was the highlight of the morning — actually deploying an agent, connecting a Knowledge Base, and building a Web UI made the knowledge sink in much faster than theory alone
- Debugging errors that came up during the lab was a valuable, real-world learning experience not found in any documentation

#### Connecting with the AgentForge community

- The workshop created a positive learning environment where everyone collaborated to solve problems and share different approaches
- Networking with other FCAJ community members helped me expand my connections and gain additional perspectives

#### Lessons learned

- **Amazon Bedrock AgentCore** is a powerful platform for building production-ready AI agents on AWS
- Integrating a **Knowledge Base** transforms a generic agent into a domain expert
- **Security first**: Integrating Amazon Cognito from the beginning is a best practice to ensure the agent only serves authorized users
- Day 1 builds the critical foundation — a solid understanding of the fundamentals makes Day 2 and Day 3 significantly easier
